## ✨ Features

- ✅ Task Management
- 🎯 Habit Tracking with Streaks
- 📝 Notes with Speech-to-Text
- 🔔 Local Notifications & Reminders
- 📅 Monthly Habit Calendar
- 🏷 Priority Tags & Categories
- 📶 Offline-First using SQLite

## 🛠 Tech Stack

- React Native
- Expo
- TypeScript
- SQLite
- Expo Notifications
